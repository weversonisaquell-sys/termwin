CORREÇÃO: DESATIVAR A COMPILAÇÃO APK E USAR O WORKFLOW PRINCIPAL PARA GERAR EXE WINDOWS

Pré-requisitos: projeto clonado em ~/TermWin; origin configurado; ZIP salvo em ~/storage/downloads/TermWin_Windows_Nativo_GitHubActions.zip.

Execute no Termux:

cd ~/TermWin && T="$HOME/tw_tmp" && rm -rf "$T" && mkdir -p "$T" && unzip -q "$HOME/storage/downloads/TermWin_Windows_Nativo_GitHubActions.zip" -d "$T" && test -f "$T/windows/TermWin.Windows.csproj" && test -f "$T/.github/workflows/build.yml" && find . -mindepth 1 -maxdepth 1 ! -name .git -exec rm -rf {} + && cp -r "$T"/. . && rm -rf "$T" && git add -A && (git diff --cached --quiet || git commit -m "Replace APK workflow with native Windows EXE build") && git push origin HEAD

IMPORTANTE:
- O arquivo .github/workflows/build.yml agora compila o Windows EXE; não compila APK.
- O workflow antigo .github/workflows/build-windows.yml foi removido para não duplicar execuções.
- O projeto Android/app continua no repositório como código-fonte, mas esse workflow não gera APK.
- O push dispara o workflow em qualquer branch. Se não iniciar, abra GitHub > Actions > Build TermWin EXE e use Run workflow.

BAIXAR:
GitHub > Actions > Build TermWin EXE > última execução concluída > Artifacts > TermWin-Windows-x64.
O artefato é ZIP e contém o executável e os recursos publicados.
