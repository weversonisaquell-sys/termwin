==========================================

Punch Combo.fbx

The original FBX files supplied for this update are included here. Reliable use on another character requires animation retargeting to that character's skeleton; bone names, hierarchy, bind pose, and coordinate conventions can differ. The editor buttons play matching clips when the currently loaded model contains a matching animation clip. They do not claim to automatically retarget incompatible skeletons.
